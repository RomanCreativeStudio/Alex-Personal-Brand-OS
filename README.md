# Alex Personal Brand OS

A lightweight system to document Alex's real journey — building businesses,
building technology, learning, and growing — and turn appropriate parts of it
into authentic content.

> Don't manufacture a life for content. Document the life you're actually
> building.

This system does not manufacture a persona. It exists to capture what's
actually happening and let content emerge from it, not the other way around.

## Core Loop

```
LIVE → THINK/ASK → CAPTURE → CLASSIFY → REVISE → EPISODE → PUBLISH → RESULT → UPDATE STORY
```

## Structure

- **STORY/** — the master narrative: `MASTER_STORY.md`, `TIMELINE.md`, `KEY_MOMENTS.md`
- **CONTENT/** — the working pipeline: `CAPTURES.md` (raw capture index) → `IDEAS.md` / `QUESTIONS.md` / `LESSONS.md` (classified) → `THEMES.md` (recurring patterns) → `CONTENT_ENGINE.md` (content opportunities) → `FORMATS.md` (platform versions) → `EPISODES.md` (developed concepts) → `RESULTS.md` (published outcomes)
- **SERIES/** — the recurring content lines: The Build, The Journey, RCS, AIMA, Faith, What I'm Learning, Real Life
- **SYSTEM/** — how the OS works: `CONTENT_RULES.md`, `VOICE.md`, `CAPTURE_PROTOCOL.md` (commands), `CAPTURE_WORKFLOW.md` (capture lifecycle), `DAILY_CAPTURE.md` (raw intake), `QUESTION_TO_CONTENT.md`, `RESULTS_LOOP.md`, `AI_COLLABORATION.md` (roles), `V1_AUDIT.md` (current state)

## How It Works

Alex is the source of truth for his own experiences, values, and decisions.
ChatGPT captures, classifies, and develops content strategy; Claude implements
and validates the repository. Neither invents Alex's experiences. See
`SYSTEM/AI_COLLABORATION.md` for the full role breakdown, `SYSTEM/CAPTURE_PROTOCOL.md`
for the supported commands (`CAPTURE`, `STORY`, `EPISODE`, `LESSON`,
`UPDATE OS`, `REVISE`), and `SYSTEM/CONTENT_RULES.md` for the rules
everything here follows.

This is a Markdown-only system by design — no database, no automation, no
dashboards. Keep it lightweight.
