# Weekly Content System — Minimum Editing

## Objective

Create a consistent documentary series without allowing content production to consume the time needed to build RCS.

## Weekly Output

**5 primary videos, Monday–Friday.**

Each video should normally require:
- 5–15 minutes filming/capture
- 10–20 minutes maximum editing
- 5 minutes upload/caption

**Target maximum editing time: ~100 minutes/week.**

If editing starts taking substantially longer, simplify the video instead of adding more effects.

## Daily Format

### Monday — Mission
One short talking-head clip or voiceover.

Show:
- This week's goal
- Current $10k number
- What needs to happen

### Tuesday — Work
Capture real work already happening.

Use:
- Screen recording
- Laptop footage
- Website build
- Outreach
- Client work

Do not stage extra scenes just for the video.

### Wednesday — Reality
One honest moment.

Examples:
- Rejection
- Problem
- Slow day
- Unexpected win
- Lesson

### Thursday — Progress
Show evidence of movement.

Examples:
- New lead
- Meeting booked
- Proposal sent
- Client payment
- Website milestone

### Friday — Weekly Recap
30–60 seconds.

Show the scoreboard and what happens next.

## Minimum-Edit Formula

```text
RAW CLIP
↓
Trim beginning/end
↓
Remove obvious dead space
↓
Auto captions
↓
One clean text hook
↓
Optional 1–3 supporting clips
↓
Music only if it helps
↓
Export
```

No elaborate transitions. No cinematic montage required for ordinary episodes.

## Editing Priority Order

1. Story clarity
2. Dead-space removal
3. Captions
4. Hook text
5. Supporting B-roll
6. Music
7. Everything else

If #1–4 are done, the video is finished.

## Batch Rule

Do not open the editor repeatedly throughout the workday.

Capture first. Edit in one short batch when possible.

## Hard Stop

If a normal episode reaches **20 minutes of editing**, stop adding polish. Export the best version and move on.
