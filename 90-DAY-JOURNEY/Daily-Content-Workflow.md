# Daily Content Workflow

## Principle

The 90-Day Journey is a documentation layer on top of the work—not a second job.

## Capture

During normal RCS work, capture only moments that naturally tell the story:

- Starting the day's work
- Outreach
- Building/designing
- Client communication
- Meetings
- Proposals
- Problems/rejections
- Wins/results

Short clips are enough. Do not repeatedly redo shots.

## Before Recording

Ask one question:

> What is happening in the journey today that someone would actually want to follow?

Record that moment.

## Edit

Use the same project/template whenever possible.

1. Duplicate the episode template.
2. Drop in the day's main clip.
3. Trim dead space.
4. Generate captions.
5. Add the hook text.
6. Add only necessary supporting footage.
7. Export.
8. Reuse the same master for other platforms.

## Publishing

Primary:
- TikTok
- Instagram Reels

Secondary:
- YouTube Shorts
- LinkedIn when the episode has a professional/business lesson

## Time Protection

The content workflow must not interrupt client delivery, outreach, meetings, or revenue-producing work.

If there is no meaningful event that day, make a simple update rather than inventing one.

## Weekly Batch

Friday recap can be prepared from the week's existing clips and numbers. This avoids creating a separate production session for the recap.

## Default Episode Length

Aim for **30–60 seconds** unless the story works better shorter.

## Definition of Done

An episode is done when:
- The story is understandable.
- The hook is clear.
- Captions are readable.
- The footage is clean enough.
- The correct number/status is accurate.
- It has been exported and queued/published.

More editing is not automatically better content.
