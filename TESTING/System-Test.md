# 90-Day Journey System Test

## Purpose

Verify the system once before Day 1 so production does not turn into constant troubleshooting.

## Content Test

- [ ] Master episode template works.
- [ ] Captions are readable.
- [ ] Plus Jakarta Sans is available.
- [ ] 1080 × 1920 / 30 FPS export works.
- [ ] Baseline grade/settings work.
- [ ] Master intro works if used.
- [ ] Final video looks good on a phone.

## Workflow Test

- [ ] Capture a short real-world clip.
- [ ] Edit it using the standard workflow.
- [ ] Finish within 20 minutes.
- [ ] Export successfully.
- [ ] Upload/queue successfully.
- [ ] Repurpose the same finished asset without rebuilding it.

## Business Protection Test

- [ ] Content production did not require a separate filming day.
- [ ] Editing did not interfere with RCS work.
- [ ] No unnecessary tools/apps were introduced.
- [ ] The process is simple enough to repeat five days/week.

## Pass Condition

The system passes when a normal episode can go from captured footage to publish-ready video in **20 minutes or less** without rebuilding the production system.
