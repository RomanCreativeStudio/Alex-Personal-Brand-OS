# Formats

Platform/format versions of existing verified content opportunities. A format
is not a new idea — it's a different delivery method for the same verified
core message. No story details are added beyond what's already in
`CONTENT/CONTENT_ENGINE.md` and its source records.

```
OPPORTUNITY → CORE MESSAGE → FORMAT → EPISODE → PLATFORM VERSION
```

## Format Record

```
ID:
SOURCE:
CORE_MESSAGE:
FORMAT:
PLATFORM:
HOOK_ANGLE:
KEY_POINTS:
SERIES:
STATUS:
```
