# DaVinci Resolve Workflow

## Role

DaVinci Resolve is the higher-control editing option. Use it when it saves time through an existing template or when a special video genuinely benefits from more control.

It is **not required for every episode**.

## Standard Workflow

1. Open the reusable 1080 × 1920 / 30 FPS project.
2. Duplicate the episode timeline.
3. Add the main clip.
4. Trim dead space.
5. Generate/use captions.
6. Add the hook text using Plus Jakarta Sans.
7. Add only useful supporting footage.
8. Apply the saved baseline grade.
9. Check audio and captions.
10. Export.

## Time Target

Normal episode: **10–20 minutes.**

If Resolve is taking longer than the equivalent CapCut workflow, use CapCut for that episode.

## Existing Test

The reusable timeline/test setup should remain the starting point rather than being rebuilt for each episode.

## Rule

The goal is to publish consistently, not to demonstrate editing skill.
