# Editing Workflow — Minimum Viable Production

## Goal

Produce publishable short-form content with the least possible editing time.

## One-Time Setup

Create one reusable project/template containing:

- 1080 × 1920 timeline
- 30 FPS
- Plus Jakarta Sans
- Caption styling
- Standard hook text placement
- Baseline color adjustment
- Audio level baseline
- Optional 7.5-second master intro

After setup, episodes should be made by duplicating the template.

## Per-Episode Workflow

1. Duplicate the master project.
2. Import/select the strongest clip.
3. Place it on the timeline.
4. Cut dead space and mistakes.
5. Add captions.
6. Add one hook/title.
7. Add supporting clips only when they improve clarity.
8. Apply the existing grade/settings.
9. Check audio and captions.
10. Export 1080 × 1920, 30 FPS.

## Time Budget

**Target: 10–20 minutes per ordinary episode.**

**Hard stop: 20 minutes.**

The exception is a special recap, launch, or intentionally cinematic piece. Those should be occasional, not the normal workflow.

## What Not To Do

- Rebuild the intro every episode.
- Color-grade every clip from scratch.
- Add transitions to every cut.
- Search for music for 20 minutes.
- Create custom graphics for ordinary updates.
- Re-record footage because it is not perfect.

## Decision Rule

Ask:

> Does this edit improve the story enough to justify the time?

If not, skip it.
