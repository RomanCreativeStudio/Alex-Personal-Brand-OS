# Caption Template

## Default

**Hook/result:** [What happened?]

Building Roman Creative Studio in public for 90 days.

Current progress: $[TOTAL] / $10,000

[One short lesson or context line.]

Follow the journey to see what happens next.

## Rules

- Keep the first line strong.
- Use real numbers only.
- Avoid exaggerated claims.
- Keep the caption readable.
- Adapt wording naturally per platform.

## Hashtags

Use a small set of relevant tags. Do not spend significant editing time researching hashtags for each post.
